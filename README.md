# SGU - C# Programming Assignments

This repository contains the lab exercises and homework assignments for the **C# Programming** course at **Saigon University (SGU)**. 

The project serves as a comprehensive practical implementation of core C# programming concepts, progressing from basic syntax and console applications to advanced object-oriented programming, collection manipulation, and data querying techniques.

## 📌 Project Overview

The assignments are structured as a modular .NET Console Application. Rather than a single monolithic script, the project is organized into separate modules to clearly demonstrate the progression of topics covered throughout the semester.

Key concepts demonstrated across the labs include:
- Basic Console I/O and Data Types.
- Arrays, Strings, and Collection Manipulation.
- Object-Oriented Programming (Classes, Objects, Properties).
- Advanced Data Querying and Transformation (LINQ, Grouping, Joins).
